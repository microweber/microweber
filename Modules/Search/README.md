# Search

Site search functionality. Full-text search across pages, posts, products, and other content.

## Structure

- Filament admin
- Livewire components
- Route definitions
- Blade views

## Usage

### Module tag

```html
<module type="search" />
```

### Publish assets

```sh
php artisan module:publish Search
```

### Views

```php
view('modules.search::index')
```
