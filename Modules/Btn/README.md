# Btn

Customizable button component with configurable text, link, style, size, and color options.

## Structure

- Filament admin
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="btn" />
```

### Publish assets

```sh
php artisan module:publish Btn
```

### Configuration

```php
config('modules.btn.name')
```

### Views

```php
view('modules.btn::index')
```
