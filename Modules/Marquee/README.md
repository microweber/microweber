# Marquee

Scrolling marquee text or content ticker for displaying announcements or featured items.

## Structure

- Filament admin
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="marquee" />
```

### Publish assets

```sh
php artisan module:publish Marquee
```

### Views

```php
view('modules.marquee::index')
```
