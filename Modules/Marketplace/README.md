# Marketplace

Module and template marketplace. Browse, install, and update modules, templates, and extensions.

## Structure

- Filament admin
- Livewire components
- Eloquent models
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="marketplace" />
```

### Publish assets

```sh
php artisan module:publish Marketplace
```

### Views

```php
view('modules.marketplace::index')
```
