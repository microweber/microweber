# Sharer

Social sharing buttons. Add share links for Facebook, Twitter, LinkedIn, and other social networks.

## Structure

- Filament admin
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="sharer" />
```

### Publish assets

```sh
php artisan module:publish Sharer
```

### Views

```php
view('modules.sharer::index')
```
