# Embed

Embed external content via URL or HTML code. Supports oEmbed for YouTube, Vimeo, Twitter, and more.

## Structure

- Filament admin
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="embed" />
```

### Publish assets

```sh
php artisan module:publish Embed
```

### Views

```php
view('modules.embed::index')
```
