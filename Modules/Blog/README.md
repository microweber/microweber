# Blog

Blog content management. Create, edit, and display blog posts with categories, tags, and pagination.

## Structure

- Filament admin
- Livewire components
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="blog" />
```

### Publish assets

```sh
php artisan module:publish Blog
```

### Views

```php
view('modules.blog::index')
```
