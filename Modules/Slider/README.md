# Slider

Image and content slider/carousel. Create responsive slideshows with transitions and autoplay.

## Structure

- Filament admin
- Eloquent models
- Blade views
- Database migrations
- Tests

## Usage

### Module tag

```html
<module type="slider" />
```

### Run migrations

```sh
php artisan module:migrate Slider
```

### Publish assets

```sh
php artisan module:publish Slider
```

### Views

```php
view('modules.slider::index')
```
