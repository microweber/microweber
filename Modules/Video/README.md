# Video

Video embed and player module. Embed videos from YouTube, Vimeo, or upload self-hosted video files.

## Structure

- Filament admin
- Route definitions
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="video" />
```

### Publish assets

```sh
php artisan module:publish Video
```

### Views

```php
view('modules.video::index')
```
