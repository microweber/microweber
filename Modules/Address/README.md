# Address

Address management for users and orders. Provides address form fields for billing and shipping in the checkout flow.

## Structure

- Eloquent models
- Route definitions
- Database migrations
- Tests

## Usage

### Module tag

```html
<module type="address" />
```

### Run migrations

```sh
php artisan module:migrate Address
```

### Publish assets

```sh
php artisan module:publish Address
```
