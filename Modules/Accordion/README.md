# Accordion

Collapsible accordion panels for organizing content into expandable sections. Users can click headers to show or hide content blocks.

## Structure

- Filament admin
- Eloquent models
- Blade views
- Database migrations
- Tests

## Usage

### Module tag

```html
<module type="accordion" />
```

### Run migrations

```sh
php artisan module:migrate Accordion
```

### Publish assets

```sh
php artisan module:publish Accordion
```

### Views

```php
view('modules.accordion::index')
```
