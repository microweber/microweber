# Shop

Core e-commerce module. Provides the shop framework including product display, cart, and checkout.

## Structure

- Filament admin
- Livewire components
- Service classes
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="shop" />
```

### Publish assets

```sh
php artisan module:publish Shop
```

### Views

```php
view('modules.shop::index')
```
