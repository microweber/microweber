# Tabs

Tabbed content panels. Organize content into switchable tabs with customizable labels.

## Structure

- Filament admin
- Eloquent models
- Blade views
- Database migrations
- Tests

## Usage

### Module tag

```html
<module type="tabs" />
```

### Run migrations

```sh
php artisan module:migrate Tabs
```

### Publish assets

```sh
php artisan module:publish Tabs
```

### Views

```php
view('modules.tabs::index')
```
