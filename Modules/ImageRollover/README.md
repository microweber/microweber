# ImageRollover

Interactive image rollover effect. One image changes to another when the user hovers over it.

## Structure

- Filament admin
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="image_rollover" />
```

### Publish assets

```sh
php artisan module:publish ImageRollover
```

### Views

```php
view('modules.image_rollover::index')
```
