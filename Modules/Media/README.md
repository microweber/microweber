# Media

Core media handling. Upload, process, and serve images, videos, and other media files.

## Structure

- Filament admin
- Eloquent models
- Service classes
- Route definitions
- Database migrations
- Tests

## Usage

### Module tag

```html
<module type="media" />
```

### Run migrations

```sh
php artisan module:migrate Media
```

### Publish assets

```sh
php artisan module:publish Media
```
