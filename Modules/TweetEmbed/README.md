# TweetEmbed

Twitter/X tweet embed module. Display individual tweets or timelines on website pages.

## Structure

- Filament admin
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="tweet_embed" />
```

### Publish assets

```sh
php artisan module:publish TweetEmbed
```

### Views

```php
view('modules.tweet_embed::index')
```
