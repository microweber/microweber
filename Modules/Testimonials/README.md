# Testimonials

Customer testimonial display. Showcase client reviews and feedback with photos and ratings.

## Structure

- Filament admin
- Eloquent models
- Blade views
- Database migrations
- Tests

## Usage

### Module tag

```html
<module type="testimonials" />
```

### Run migrations

```sh
php artisan module:migrate Testimonials
```

### Publish assets

```sh
php artisan module:publish Testimonials
```

### Views

```php
view('modules.testimonials::index')
```
