# MediaLibrary

Media library browser with folder organization, search, filtering, and Unsplash integration.

## Structure

- Filament admin
- Route definitions
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="media_library" />
```

### Publish assets

```sh
php artisan module:publish MediaLibrary
```

### Views

```php
view('modules.media_library::index')
```
