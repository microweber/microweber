# FacebookLike

Facebook Like button integration. Add a Like button to pages for social engagement.

## Structure

- Filament admin
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="facebook_like" />
```

### Publish assets

```sh
php artisan module:publish FacebookLike
```

### Views

```php
view('modules.facebook_like::index')
```
