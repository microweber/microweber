# Checkout

E-commerce checkout process. Handle shipping address, payment method selection, and order placement.

## Structure

- Filament admin
- Livewire components
- HTTP controllers
- Service classes
- Route definitions
- Blade views
- Tests

## Usage

### Module tag

```html
<module type="checkout" />
```

### Publish assets

```sh
php artisan module:publish Checkout
```

### Views

```php
view('modules.checkout::index')
```
