## BUG-1 (HIGH): `<module type="btn"/>` renders as a tiny left-aligned pill, never fills its column

**Symptom**
Drop a `btn` module into any column wrapper (`col-12`, `col-md-6`,
`col-md-3`). The rendered button stays at its intrinsic content
width (~80px) and aligns to the left edge — there's no centering,
no full-width option. Operators land on a "Button" labelled pill
floating in a sea of empty whitespace and have no obvious way to
make it span the column.

Visible in all three audit sections at desktop 1280px AND mobile
390px. The button does NOT inherit the column's `text-align`
either, so even centering the wrapper doesn't help.

**File**
`Modules/Btn/resources/views/templates/default.blade.php`
`Modules/Btn/resources/views/templates/bootstrap.blade.php`

**Fix idea**
Either (a) wrap the rendered `<a>`/`<button>` in a flex row with
configurable justify (start/center/end + stretch), or (b) at
minimum match the parent column's `text-align`. Stretch should
also be opt-in via a module option.

## BUG-2 (HIGH): `<module type="picture"/>` renders at intrinsic image size, ignores column width

**Symptom**
Drop a `picture` module into a `col-12`. The image renders at
its native pixel size (~330×220 in the test fixture's seed
image) regardless of the column being 1240px wide. On
narrow columns (col-md-3) the image often overflows.

The native template needs `class="img-fluid"` or
`max-width: 100%; height: auto;` on the wrapping element.

**File**
`Modules/Pictures/resources/views/templates/default.blade.php`
(single picture branch — also affects Picture module's view)

**Fix idea**
Ensure all `<img>` tags in module templates carry
`class="img-fluid"` (Bootstrap helper that maps to
`max-width:100%; height:auto;`). Stop trusting image
dimensions to be sane.

## BUG-4 (MEDIUM): Contact form labels overflow on narrow column (col-md-3)

**Symptom**
Drop a `contact_form` into a `col-md-3` (approximately 290px on
a desktop). The "Leave a Message" heading and the "Name" /
"Email" / "Message" labels stay readable but the input fields
shrink so far that the placeholder is clipped, AND the
"Send Message" button drops to a new line with awkward
spacing.

**File**
`Modules/ContactForm/resources/views/templates/default.blade.php`

**Fix idea**
Add `@container` queries (or fall back to `@media min-width:
500px`) to flow the label-above-input layout to a
label-beside-input layout on narrow columns. Or document that
contact_form requires col-md-6+ via `min-width: 250px` on the
inputs.

## BUG-5 (MEDIUM): Newsletter form button is centered and small even when alone in its column

**Symptom**
Drop a `newsletter` module into `col-md-3`. The "Submit" button
lands centered horizontally at ~80px wide. Operators expect a
full-width Submit (the standard email-signup pattern). Also,
the form's "Newsletter" heading is heavy/bold but the input
fields are subtly different in style than the rest of the
audit page (rounded vs sharp corners).

**File**
`Modules/Newsletter/resources/views/templates/default.blade.php`

**Fix idea**
Wrap the button in `d-grid` (Bootstrap 5's full-width grid
wrapper) so it stretches by default. Match input styling to
ContactForm.

## BUG-6 (LOW): Top header overlap on narrow phones (≤320px) — Site Logo + hamburger collide

**Symptom**
At 320px viewport, "Site Logo" text overlaps with the
hamburger icon on the right. At 390px there's a small visible
gap, but the spacing is very tight.

**File**
`Templates/Bootstrap/resources/views/modules/layouts/templates/menus/skin-1.blade.php`

**Fix idea**
Add `text-overflow: ellipsis` to the logo text + a `min-width:
0` flex behavior so it can shrink instead of pushing the
hamburger off-screen.
