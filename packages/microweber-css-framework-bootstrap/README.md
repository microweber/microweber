# Css Framework Bootstrap

Shared Microweber CSS framework based on Bootstrap with semantic --mw- CSS variables

Part of the [Microweber](https://microweber.com) CMS.

## Installation

```bash
composer require microweber-packages/microweber-css-framework-bootstrap
```
