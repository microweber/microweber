# Cdn Sync

Standalone CDN sync package for Laravel. Syncs any Eloquent model's files to S3-compatible storage via a polymorphic sync log.

Part of the [Microweber](https://microweber.com) CMS.

## Installation

```bash
composer require microweber-packages/microweber-cdn-sync
```
