# Filesystem

Standalone Laravel filesystem service: file utilities, path normalization, directory operations, extension validation, and SVG sanitization

Part of the [Microweber](https://microweber.com) CMS.

## Installation

```bash
composer require microweber-packages/microweber-filesystem
```
