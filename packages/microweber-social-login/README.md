# Social Login

Social login package for Microweber CMS and standalone Laravel apps – provides OAuth login via Facebook, Google, GitHub, Twitter, LinkedIn and Microweber

Part of the [Microweber](https://microweber.com) CMS.

## Installation

```bash
composer require microweber-packages/microweber-social-login
```
